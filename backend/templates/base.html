Cómo actualizar la base y esta página

Ejecuta el script para consultar las publicaciones y conservar las nuevas emisiones. El HTML se escribe de nuevo al terminar. Puedes recargarlo manualmente o dejar activada su relectura cada 60 segundos. La consulta al COES solo la realiza el script.

python actualizar_base.py

Para una fecha concreta: python actualizar_base.py --fecha 2026-11-03. Conserva la carpeta completa para mantener los enlaces a los originales y al Excel consolidado.
